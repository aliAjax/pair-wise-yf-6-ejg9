# 家庭维修事项

端口规划：`5114`

```bash
npm install
npm run dev
```

第一版闭环：记录维修问题、按状态查看、更新处理状态、统计未完成预计费用，支持照片链接并使用localStorage保存数据。

第二版：维修事项可挂最多两个同位置前置工序，开工（含直接完工）前校验前置全部完工；循环或跨位置依赖拒绝保存并指出冲突事项；上游被删除或重新打开时，下游未完工事项回到待处理（已完成记录保留，且不再透过已完成项向下传导）；首页按可开工 / 被阻塞 / 已完成分组，费用只统计未完成事项。

业务拆分：

- `src/dependencies.js` 依赖规则：前置数量上限、同位置校验、循环检测、阻塞判断
- `src/statusFlow.js` 状态流转：开工守卫、上游变更时的下游级联重置
- `src/storage.js` 本地存储：localStorage 读写与旧数据归一化
