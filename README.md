# 家庭维修事项

端口规划：`5114`

```bash
npm install
npm run dev
```

第一版闭环：记录维修问题、按状态查看、更新处理状态、统计未完成预计费用，支持照片链接并使用localStorage保存数据。

第二版：维修事项支持前置依赖——每个事项最多挂两个同位置前置项，循环或跨位置依赖拒绝保存并指出冲突事项；开工（处理中）前要求前置项全部完工；上游被删除或重新打开时，未完成的下游自动回到待处理（已完成记录保留）。首页按可开工、被阻塞、已完成分组展示，费用统计只算未完成事项。业务代码分为 `src/dependencies.js`（依赖规则）、`src/statusFlow.js`（状态流转）、`src/storage.js`（本地存储）。
